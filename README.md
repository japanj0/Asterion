
# Asterion - защита корпоративной среды и не только!

## Системные требования Asterion

### Операционная система(рекомендованная)
- **Windows** 10/11
- **Linux** (Ubuntu 26.04; Arch (снэпшот от 30 августа 2026, ядро - 7.1.5)) - Xorg(X11) only

### Аппаратное обеспечение

| Компонент | Минимум | Рекомендуется |
|-----------|---------|---------------|
| Процессор | 64-bit (x86_64), 1.5 ГГц | Intel Core i5+ / AMD Ryzen 5+ |
| ОЗУ | 4 ГБ | 8 ГБ |
| Диск | 1 ГБ | 16+ ГБ |
| Сеть | Простейший модем телефона | Стабильное подключение(wi-fi) |

---

## Возможности

1. **Защищённый чат и мультимедиа** (SSL/TLS + Fernet + PBKDF2HMAC)

2. **Просмотр экрана сотрудника** (OpenCV, захват + стриминг, защищённый алгоритмом Fernet)

3. **Система мёртвой руки** - в случае отключения сервера - блокировка компьютеров сотрудников

4. **Само-блокировка пользователем** - по желанию админа, пользователь может по нажатию кнопки удалить всю историю переписки(у себя) и заблокировать свой ПК 

5. **Секретные мета-данные в файлах** - любые файлы, скачиваемые пользователем, подписываются специальной секретной стеганографической подписью с его ФИО и датой скачивания

6. **Мониторинг действий пользователя** - USB-подключения, основная информация о ПК, история захода и выхода, работа с отдельными файлами, открытие приложений

7. **Блокировка ПК сотрудника администратором**

8. **Отправка администратором экстренных уведомлений** на ПК сотрудников (QMessageBox)

9. **Возможность загрузки журнала аудита действий определенных пользователей**
 
10. **Тотальное логирование действий пользователя**

11. **Возможность Авто-бана по ключевым словам** - блокировка компьютера, если пользователь попытается открыть тот или иной запрещенный информационный ресурс или приложение

## Сфера применения 
1. **Корпоративный контроль сотрудников**
   
2. **Удобный чат для секретных переписок**
   
3. **Оптимизация учебного процесса на уроках информатики**

## Установка и запуск

**Windows**
Скачайте готовый exe и запустите

**Linux**
Скачайте готовый appimage и выполните

```bash
chmod +x названиеAPPIMAGE.appimage
```
затем запустите из файловой системы

<table>
  <tr>
    <td style="color: red; font-weight: bold;">Вопрос:</td>
    <td>Насколько сервер защищён от атак?</td>
  </tr>
  <tr>
    <td style="color: blue; font-weight: bold;">Ответ:</td>
    <td>Сервер Asterion имеет многоуровневую защиту: все соединения проходят через SSL/TLS с самоподписанным сертификатом, что исключает перехват и подмену трафика. Данные дополнительно шифруются алгоритмом Fernet с ключами, полученными через PBKDF2HMAC. Сервер автоматически блокирует IP-адреса после 5 неудачных попыток авторизации, ограничивает количество одновременных подключений с одного адреса и использует систему таймаутов для предотвращения DDoS-атак. В случае компрометации пароля - злоумышленник не сможет расшифровать историю переписки и файлы, так как они хранятся в зашифрованном виде с отдельным ключом, который не зависит от пароля сервера.</td>
  </tr>
</table>

  <tr>
    <td style="color: blue; font-weight: bold;">Ответ:</td>
    <td>Рекомендуется использовать Distrobox - инструмент для создания изолированных контейнеров с выбранным дистрибутивом. Это позволяет запускать приложение в стабильной среде без конфликтов с основной системой.<br><br>
    
<b>Инструкция:</b><br><br>
    
1. Установите Distrobox:<br>
<b>Ubuntu:</b> <code>sudo apt install distrobox</code><br>
<b>Arch:</b> <code>sudo pacman -S distrobox</code><br><br>

2. Создайте контейнер с фиксированной версией Arch Linux:<br>
<code>distrobox create -i archlinux:base-20260830.0.582275 -n asterion-arch-fixed -y</code><br><br>

3. Войдите в контейнер:<br>
<code>distrobox enter asterion-arch-fixed</code><br><br>

4. Перейдите в папку с AppImage и распакуйте его:<br>
<code>cd ~/Downloads</code><br>
<code>./AsterionUser-x86_64.AppImage --appimage-extract</code><br><br>

5. Запустите приложение из распакованной директории:<br>
<code>cd squashfs-root</code><br>
<code>./AppRun</code><br><br>

Контейнер полностью изолирован от основной системы, поэтому любые конфликты библиотек и версий GCC не повлияют на его работу.</td>
  </tr>

1. <code>sudo apt update && sudo apt install xorg -y</code><br>
2. Для KDE Plasma: <code>sudo apt install plasma-session-x11 -y</code><br><br>
<b>Инструкция для Arch Linux:</b><br>
1. <code>sudo pacman -Syu xorg-server</code><br>
2. Для KDE Plasma: <code>sudo pacman -S plasma-workspace-x11</code><br><br>
<b>Запуск:</b><br>
1. Перезагрузите ПК: <code>sudo reboot</code><br>
2. На экране входа нажмите на шестеренку и выберите сессию <b>"Plasma (X11)"</b> или <b>"GNOME на Xorg"</b>.</td>
